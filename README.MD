# monorepo和changeset集成测试


仓库整体使用 `pnpm workspace` 协议作为内部管理


发包工具采用 `changesets`

## 本仓库使用预设

本仓库预设您已经在本地安装了`verdaccio`作为您的私有npm仓库

正如您在本仓库根目录下看到的 `.npmrc` 一样
